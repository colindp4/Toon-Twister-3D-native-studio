# dirplayer-rs vm-rust component

This source tree is included to provide the corresponding source for the asset-converter executables in the parent `Tools/AssetConverter` folder. It is from the `dirplayer-rs` project and is licensed under GPL-3.0-only; see `../LICENSE`.

The two bundled converter examples are `examples/w3d_export.rs` and `examples/audio_export.rs`. They use the library in `src` and the relative `../xtra-sdk` crate.
